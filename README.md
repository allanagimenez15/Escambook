# EscamBook 📚♻️

**EscamBook** é uma plataforma digital inovadora e gratuita dedicada à troca de livros entre usuários. O projeto visa democratizar o acesso à leitura no Brasil e mitigar o desperdício gerado pelo consumo linear, incentivando a economia colaborativa e circular.

---

## 📌 Escopo do Projeto

*   **Objetivo Geral:** Democratizar o acesso à leitura através de uma plataforma web responsiva e gratuita.
*   **Público-Alvo:** Estudantes universitários/ensino médio, leitores ávidos e pessoas ambientalmente conscientes.
*   **Tecnologias Planejadas:** Frontend responsivo integrado à infraestrutura robusta do Firebase.
